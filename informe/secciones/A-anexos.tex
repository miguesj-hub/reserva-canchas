Los scripts completos se mantienen versionados junto con la implementación.
Las siguientes rutas permiten consultar la versión exacta aplicada por cada
microservicio, incluidos los datos semilla:

\begin{itemize}

  \url{https://github.com/miguesj-hub/reserva-canchas/tree/main/infra/postgres/init}
  \item Migraciones de usuarios:
  \url{https://github.com/miguesj-hub/reserva-canchas/tree/main/backend/ms-usuarios/src/main/resources/db/migration}
  \item Migraciones de canchas:
  \url{https://github.com/miguesj-hub/reserva-canchas/tree/main/backend/ms-canchas/src/main/resources/db/migration}
  \item Migraciones de reservas:
  \url{https://github.com/miguesj-hub/reserva-canchas/tree/main/backend/ms-reservas/src/main/resources/db/migration}
\end{itemize}
